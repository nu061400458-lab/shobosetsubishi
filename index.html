オームの法則

$V = I \times R$
（電圧 $V$）＝（電流 $A$）$\times$（抵抗 $\Omega$）
🔑 重要ポイント：この公式は「変形」して至るところに代入される！

$V = I \times R$ は単体で使うだけでなく、電圧か電流のどちらかが分からない問題で、他の公式に代入するための"つなぎ役"として何度も登場します。3つの形を自在に使い分けられるようにしておくことが重要です。

  • $V = I \times R$（電圧を求める）
  • $I = \frac{V}{R}$（電流を求める）
  • $R = \frac{V}{I}$（抵抗を求める）
【具体例】
電力の公式 $P = V \times I$ において、問題文で「電圧 $V$」が与えられていない場合があります。
そのとき、$V$ の部分にオームの法則 $V = I \times R$ を丸ごと代入すると…

$P = (I \times R) \times I = $ $I^2 \times R$

つまり「電圧が分からないけど電流と抵抗は分かる」といった問題でも、オームの法則を一度経由するだけで必ず解けるようになります。
Q.$10\ \Omega$ の抵抗に $2\text{V}$ の電圧をかけたときに流れる電流の値は？
解答と解説を見る
✅ 0.2 A
公式を変形して $I = \frac{V}{R}$ とします。
$I = \frac{2}{10} = 0.2\text{ A}$ となります。

電力

$P = V \times I$
（電力 $W$）＝（電圧 $V$）$\times$（電流 $A$）
Q.電圧 $6\text{V}$ の電源に抵抗を接続し、$0.5\text{A}$ の電流が流れたとき、電力 $P$ の値は？
解答と解説を見る
✅ 3 W
$P = 6 \times 0.5 = 3\text{ W}$
Q.$10\ \Omega$ の抵抗の電熱線に $2\text{V}$ の電圧をかけるとき、消費電力 $P$ の値は？
ヒント：電力（I）が分からないときには、まず最初にオームの法則（V = I×R）を使うよ
解答と解説を見る
✅ 0.4 W
まずオームの法則で電流を求めます。
$I = \frac{2}{10} = 0.2\text{ A}$。
次に $P = 2 \times 0.2 = 0.4\text{ W}$
（※ $P = \frac{V^2}{R}$ に代入して $\frac{4}{10}=0.4\text{W}$ としても計算可能です）
Q.$10\ \Omega$ の抵抗に $2\text{A}$ の電流を流したとき、この抵抗で消費される電力 $P$ の値は？
ヒント：電圧（V）が分からないときには、まず最初にオームの法則（V = I×R）を使うよ
解答と解説を見る
✅ 40 W
まずオームの法則で電圧を求めます。
$V = 2 \times 10 = 20\text{ V}$。
次に $P = 20 \times 2 = 40\text{ W}$
（※公式 $P = I^2 \times R$ を使い、$2^2 \times 10 = 40\text{W}$ と計算する方が早いです）

合成抵抗（直列・並列）

直列： $R = R_1 + R_2 + R_3$

並列： $R = \frac{1}{\frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}}$
Q.$4\ \Omega$、$6\ \Omega$、$10\ \Omega$ の3つの抵抗をすべて直列につないだ。全体の合成抵抗 $R$ は？
解答と解説を見る
✅ 20 $\Omega$
直列はそのまま足し算をします。
$R = 4 + 6 + 10 = 20\ \Omega$
Q.$10\ \Omega$、$20\ \Omega$、$20\ \Omega$ の3つの抵抗をすべて並列につないだ。全体の合成抵抗 $R$ は？
解答と解説を見る
✅ 5 $\Omega$
並列なので、逆数の和の公式を使います。
分母を $20$ に揃えて（通分して）足し算をします。
$\frac{1}{R} = \frac{1}{10} + \frac{1}{20} + \frac{1}{20}$
$\frac{1}{R} = \frac{2}{20} + \frac{1}{20} + \frac{1}{20}$
$\frac{1}{R} = \frac{4}{20}$
約分して $\frac{1}{R} = \frac{1}{5}$ となるため、ひっくり返して $R = 5\ \Omega$ となります。
Q.$5\ \Omega$ の抵抗 $R_1$ と、並列につながれた $12\ \Omega$ と $6\ \Omega$ の抵抗組（$R_2, R_3$）を直列につないだ。合成抵抗は？
解答と解説を見る
✅ 9 $\Omega$
先に並列になっている $12\ \Omega$ と $6\ \Omega$ の部分（$R_{並列}$ とします）を計算します。
$\frac{1}{R_{並列}} = \frac{1}{12} + \frac{1}{6}$
$\frac{1}{R_{並列}} = \frac{1}{12} + \frac{2}{12}$
$\frac{1}{R_{並列}} = \frac{3}{12} = \frac{1}{4}$
よって $R_{並列} = 4\ \Omega$。
これと直列の $5\ \Omega$ を足し算して、$5 + 4 = 9\ \Omega$
Q.直列につないだ $3\ \Omega$ と $5\ \Omega$ の枝Aと、それに対し並列な $8\ \Omega$ の抵抗Bがある。合成抵抗は？
解答と解説を見る
✅ 4 $\Omega$
先に上の枝Aの直列部分（$R_{直列}$ とします）を計算します。
$R_{直列} = 3 + 5 = 8\ \Omega$
これと下の $8\ \Omega$ の抵抗が並列になっているので、全体の抵抗 $R$ は
$\frac{1}{R} = \frac{1}{8} + \frac{1}{8}$
$\frac{1}{R} = \frac{2}{8} = \frac{1}{4}$
よって $R = 4\ \Omega$
Q.並列の $20\ \Omega$ と $20\ \Omega$（組A）と、並列の $30\ \Omega$ と $60\ \Omega$（組B）を直列につないだ。合成抵抗は？
解答と解説を見る
✅ 30 $\Omega$
それぞれの組の並列部分を先に計算します。
組A（$R_A$ とします）：
$\frac{1}{R_A} = \frac{1}{20} + \frac{1}{20} = \frac{2}{20} = \frac{1}{10}$ より $R_A = 10\ \Omega$
組B（$R_B$ とします）：
$\frac{1}{R_B} = \frac{1}{30} + \frac{1}{60}$
$\frac{1}{R_B} = \frac{2}{60} + \frac{1}{60} = \frac{3}{60} = \frac{1}{20}$ より $R_B = 20\ \Omega$
最後に2つを直列として足し算します。
$10 + 20 = 30\ \Omega$

直列・並列回路の電圧と電流

直列（電流）： $I_1 = I_2 = I_3$
直列（電圧）： $V = V_1 + V_2 + V_3$

並列（電流）： $I = I_1 + I_2 + I_3$
並列（電圧）： $V_1 = V_2 = V_3$
Q.$10\ \Omega, 15\ \Omega, 25\ \Omega$ を直列接続し、全体に $0.4\text{A}$ の電流が流れている。各電圧 $V_1, V_2, V_3$ と全体電圧 $V$ は？
解答と解説を見る
✅ $V_1 = 4\text{V},\ V_2 = 6\text{V},\ V_3 = 10\text{V}$。全体 $V = 20\text{V}$
$V_1 = 10 \times 0.4 = 4\text{V}$
$V_2 = 15 \times 0.4 = 6\text{V}$
$V_3 = 25 \times 0.4 = 10\text{V}$
全体の電圧は各電圧の足し算になるので、 $V = 4 + 6 + 10 = 20\text{V}$
Q.3つの抵抗が並列につながれた回路で、各枝の電流が $I_1 = 1\text{A}$、$I_2 = 2\text{A}$、$I_3 = 4\text{A}$ のとき、全体の電流 $I$ はいくらですか。
解答と解説を見る
✅ 7 A
並列回路では、各枝に分かれて流れる電流をすべて足し合わせると全体の電流になります。
$I = I_1 + I_2 + I_3$
$I = 1 + 2 + 4 = 7\text{A}$

ブリッジ回路

平衡条件： $R_1 \times R_4 = R_2 \times R_3$
対角の積が等しい（平衡状態）とき、中央には電流が流れない。
【ブリッジ回路の基本構成】
Q.電源 $60\text{V}$。$R_1=15\ \Omega, R_2=30\ \Omega, R_3=45\ \Omega, R_4=R_x\ \Omega$ で平衡状態。$R_x$ の値は？
解答と解説を見る
✅ 90 $\Omega$
対角線の掛け算をイコールで結びます。
$15 \times R_x = 30 \times 45$
$15 \times R_x = 1350$
$R_x = 90\ \Omega$
Q.電源 $24\text{V}$、$R_1=10\ \Omega, R_2=20\ \Omega, R_3=30\ \Omega, R_4=60\ \Omega$、中央 $R_5=50\ \Omega$。
中央に流れる電流 $I_5$ と、全電流 $I$ を求めよ。
解答と解説を見る
✅ $I_5 = 0\text{ A}$、 全電流 $I = 0.9\text{ A}$
$10 \times 60 = 20 \times 30 = 600$ となり、条件を満たすため平衡状態。中央には電流は流れないので $I_5=0$。

中央を無視して「上の直列」「下の直列」の並列回路として計算します。
上側の合成 $10+30=40\ \Omega$ (流れる電流 $24 \div 40 = 0.6\text{A}$)
下側の合成 $20+60=80\ \Omega$ (流れる電流 $24 \div 80 = 0.3\text{A}$)
全電流 $I = 0.6 + 0.3 = 0.9\text{A}$

コンデンサ（電荷と静電容量）

$Q = C \times V$
（電荷 $C$ クーロン）＝（静電容量 $F$ ファラド）$\times$（電圧 $V$）
Q.静電容量 $20\ \mu\text{F}$ のコンデンサに $100\text{V}$ の電圧を加えた。蓄えられる電荷 $Q$ [C] は？
解答と解説を見る
✅ 0.002 C ($2 \times 10^{-3}\text{ C}$)
$\mu$（マイクロ）は $10^{-6}$ 倍です。
$Q = (20 \times 10^{-6}) \times 100 = 2000 \times 10^{-6} = 0.002\text{ C}$
Q.$200\text{V}$ の電圧を加えると $0.01\text{ C}$ の電荷が蓄えられた。静電容量 $C$ [$\mu\text{F}$] は？
解答と解説を見る
✅ 50 $\mu\text{F}$
$C = \frac{Q}{V} = \frac{0.01}{200} = 0.00005\text{ F}$。
これを $\mu\text{F}$ に直すため $1,000,000$ 倍して $50\ \mu\text{F}$。
Q.$50\ \mu\text{F}$ のコンデンサに $0.006\text{ C}$ の電荷がある。電圧 $V$ [V] は？
解答と解説を見る
✅ 120 V
$V = \frac{Q}{C} = \frac{0.006}{50 \times 10^{-6}} = \frac{0.006}{0.00005} = 120\text{ V}$

コンデンサの合成容量

並列（足し算）： $C = C_1 + C_2 + C_3$
直列（逆数）： $C = \frac{1}{\frac{1}{C_1} + \frac{1}{C_2} + \frac{1}{C_3}}$
Q.$2\ \mu\text{F}, 3\ \mu\text{F}, 5\ \mu\text{F}$ を並列に接続。合成容量 $C$ は？
解答と解説を見る
✅ 10 $\mu\text{F}$
コンデンサの並列はそのまま足します。
$C = 2 + 3 + 5 = 10\ \mu\text{F}$
Q.$6\ \mu\text{F}, 12\ \mu\text{F}, 4\ \mu\text{F}$ を直列に接続。合成容量 $C$ は？
解答と解説を見る
✅ 2 $\mu\text{F}$
コンデンサの直列は逆数の和で計算します。
分母を $12$ に揃えて（通分して）足し算をします。
$\frac{1}{C} = \frac{1}{6} + \frac{1}{12} + \frac{1}{4}$
$\frac{1}{C} = \frac{2}{12} + \frac{1}{12} + \frac{3}{12}$
$\frac{1}{C} = \frac{6}{12} = \frac{1}{2}$
ひっくり返して $C = 2\ \mu\text{F}$
Q.$2\mu\text{F}$ と $4\mu\text{F}$ のコンデンサを並列につなぎ、それらに $6\mu\text{F}$ のコンデンサを直列につなぎました。回路全体の合成容量は何 $\mu\text{F}$ ですか。
解答と解説を見る
✅ 3 $\mu\text{F}$
先に並列になっている $2\mu\text{F}$ と $4\mu\text{F}$ の部分（$C_{並列}$ とします）を計算します。
$C_{並列} = 2 + 4 = 6\ \mu\text{F}$
これと直列になっている $6\ \mu\text{F}$ を計算します。
分母を $6$ に揃えて足し算をします。
$\frac{1}{C} = \frac{1}{6} + \frac{1}{6}$
$\frac{1}{C} = \frac{2}{6}$
約分して $\frac{1}{C} = \frac{1}{3}$ となるため、ひっくり返して $C = 3\ \mu\text{F}$

抵抗値の計算 （ここは計算問題はあまり出ない）

$R = \rho \times \frac{l}{S}$
（抵抗 $\Omega$）＝（抵抗率 $\Omega\cdot\text{m}$）$\times$（長さ $m$）$\div$（断面積 $\text{m}^2$）
Q.抵抗率 $2 \times 10^{-6}\ \Omega\cdot\text{m}$、長さ $50\text{m}$、断面積 $1 \times 10^{-4}\ \text{m}^2$ の導線の抵抗 $R$ は？
解答と解説を見る
✅ 1 $\Omega$
$R = (2 \times 10^{-6}) \times \frac{50}{1 \times 10^{-4}} = \frac{100 \times 10^{-6}}{10^{-4}} = 100 \times 10^{-2} = 1\ \Omega$
Q.抵抗 $10\ \Omega$ の金属線。長さを2倍、断面積を半分（0.5倍）にすると抵抗は何 $\Omega$ になる？
解答と解説を見る
✅ 40 $\Omega$
公式より、抵抗は「長さに比例」「断面積に反比例」します。
長さ2倍で抵抗は2倍。断面積半分（細くなる）で電流が通りにくくなりさらに2倍。
よって $10 \times 2 \times 2 = 40\ \Omega$
Q.抵抗率 $1.6 \times 10^{-7}\ \Omega\cdot\text{m}$、断面積 $2 \times 10^{-6}\ \text{m}^2$。抵抗を $4\ \Omega$ にしたい。必要な長さ $l$ は？
解答と解説を見る
✅ 50 m
$4 = (1.6 \times 10^{-7}) \times \frac{l}{2 \times 10^{-6}}$
$4 = 0.08 \times l$
$l = 50\text{m}$

ジュール熱

$Q = V \times I \times t$
（熱 $J$）＝（電圧 $V$）$\times$（電流 $A$）$\times$（時間：秒 $s$）
Q.$100\text{V}, 5\text{A}$ で 2分間 使用した時のジュール熱 $Q$ [J] は？
解答と解説を見る
✅ 60,000 J
時間は秒に直して計算します。（$2\text{分} = 120\text{秒}$）
$100\text{V} \times 5\text{A} \times 120\text{秒} = 60,000\text{J}$
Q.$20\ \Omega$ の抵抗に $2\text{A}$ を 30秒間 流した時のジュール熱 $Q$ [J] は？
ヒント：電圧（V）が分からないときには、まず最初にオームの法則（V = I×R）を使うよ
解答と解説を見る
✅ 2,400 J
まずオームの法則で $V = 2\text{A} \times 20\ \Omega = 40\text{V}$。
$Q = 40\text{V} \times 2\text{A} \times 30\text{秒} = 2,400\text{J}$
Q.$100\text{V}, 2\text{A}$ のヒーターで $12,000\text{J}$ 発生させるには何秒間（何分間）必要か？
解答と解説を見る
✅ 60秒間 （1分間）
$12,000 = 100 \times 2 \times t$
$12,000 = 200 \times t$
$t = 60\text{秒} = 1\text{分}$

クーロンの法則 （ここは計算問題はあまり出ない）

$F = k \times \frac{q_1 \times q_2}{r^2}$
（力 $N$）＝（比例定数 $9 \times 10^9$）$\times$（電荷 $C$）$\times$（電荷 $C$）$\div$（距離 $m$ の2乗）
Q.真空中で $2 \times 10^{-6}\text{ C}$ と $3 \times 10^{-6}\text{ C}$ が $3\text{m}$ 離れている。静電気力 $F$ [N] は？
解答と解説を見る
✅ 0.006 N ($6 \times 10^{-3}\text{ N}$)
$F = (9 \times 10^9) \times \frac{(2 \times 10^{-6}) \times (3 \times 10^{-6})}{3^2}$
$= 9 \times 10^9 \times \frac{6 \times 10^{-12}}{9}$
$= 6 \times 10^{-3}\text{ N}$

インピーダンス

$V = I \times Z$ （電圧＝電流 $\times$ インピーダンス）
RLC直列インピーダンス： $Z = \sqrt{R^2 + (X_L - X_c)^2}$
※ $X_L$: コイル(誘導), $X_c$: コンデンサ(容量)。無いものは $0$ とみなす。
Q.$R = 4\ \Omega$, $X_L = 9\ \Omega$, $X_c = 6\ \Omega$ を直列接続。インピーダンス $Z$ は？
解答と解説を見る
✅ 5 $\Omega$
$Z = \sqrt{4^2 + (9 - 6)^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5\ \Omega$
Q.抵抗 $R = 8\ \Omega$ と、$X_c = 6\ \Omega$ のコンデンサーの直列接続。インピーダンス $Z$ は？
解答と解説を見る
✅ 10 $\Omega$
コイルが無いので $X_L=0$ として計算します。
$Z = \sqrt{8^2 + 6^2} = \sqrt{64 + 36} = \sqrt{100} = 10\ \Omega$
Q.抵抗 $R = 12\ \Omega$ と、$X_L = 5\ \Omega$ のコイルの直列接続。インピーダンス $Z$ は？
解答と解説を見る
✅ 13 $\Omega$
コンデンサが無いので $X_c=0$ として計算します。
$Z = \sqrt{12^2 + 5^2} = \sqrt{144 + 25} = \sqrt{169} = 13\ \Omega$

変圧器

$\frac{V_1}{V_2} = \frac{N_1}{N_2} = \frac{I_2}{I_1}$
$V_1 : V_2 = N_1 : N_2 = I_2 : I_1$ （比の形）

（電圧は巻数に比例、電流は巻数に反比例）
Q.2次側の巻数 $N_2$ を 4倍 にした。$V_2$ は $V_1$ の何倍？ $I_2$ は $I_1$ の何倍？
解答と解説を見る
✅ 電圧は 4倍、電流は $\frac{1}{4}$ 倍 (0.25倍)
電圧は巻数に比例し、電流は反比例します。
Q.$V_1$ を 2次側で $\frac{1}{5}$倍に下げた。巻数 $N_2$ は $N_1$ の何倍？ 1次電流 $I_1$ は $I_2$ の何倍？
解答と解説を見る
✅ 巻数は $\frac{1}{5}$ 倍、$I_1$ は $I_2$ の $\frac{1}{5}$ 倍
電圧が1/5なら巻数も1/5。
電流は反比例で $I_2$ が5倍大きくなるため、「$I_1$ 視点」では $\frac{1}{5}$倍となります。
Q.1次電流 $I_1$ が 2次電流 $I_2$ の 3倍 流れている。巻数 $N_2$ は $N_1$ の何倍？ $V_2$ は $V_1$ の何倍？
解答と解説を見る
✅ 巻数は 3倍、電圧は 3倍
$I_1$ が大きい＝1次側が低電圧。
電流が $I_1 : I_2 = 3 : 1$ なので、巻数・電圧は逆比の $N_1 : N_2 = 1 : 3$ になります。

計器の接続

電圧計(V) は、測定したい回路と 並列 に接続する。
電流計(A) は、測定したい回路と 直列 に接続する。
